## 에러 핸들러

### 자동차 이름 유효성 검사

요구사항

- 최소 1대 이상의 자동차 이름을 입력해야 한다.
- 자동차 이름이 공백일 수 없다.

구현

- 입력받은 자동차 이름 배열(carNames)의 length가 0인지 확인하고, 0이면 [ERROR]를 호출한다.
- 배열의 some 메서드를 사용해, name.length === 0 (빈 문자열)인 이름이 하나라도 있는지 검사하고, 발견되면 [ERROR]를 호출한다.

### 시도 횟수 유효성 검사

요구사항

- 시도할 횟수는 1 이상의 숫자여야 한다.
- 숫자가 아닌 값(문자, 공백 등)이 입력되면 예외 처리한다.

구현

- 입력받은 tryCount 값이 1보다 작은지 (< 1) 확인한다.
- isNaN(tryCount)를 사용해 tryCount가 유효한 숫자가 맞는지 확인한다.
- 두 조건 중 하나라도 만족하면 [ERROR]를 호출한다.
