## 에러 핸들러

### 자동차 이름 유효성 검사

요구사항

- 최소 1대 이상의 자동차 이름을 입력해야 한다.
- 자동차 이름이 공백일 수 없다.

구현

- 입력받은 자동차 이름 배열(carNames)의 length가 0인지 확인하고, 0이면 [ERROR]를 호출한다.
- 배열의 some 메서드를 사용해, name.length === 0인 이름이 하나라도 있거나 name.length > 5인 경우를 검사하고, 발견되면 [ERROR]를 호출한다.

### 시도 횟수 유효성 검사

요구사항

- 시도할 횟수는 1 이상의 숫자여야 한다.
- 숫자가 아닌 값(문자, 공백 등)이 입력되면 예외 처리한다.

구현

- 사용자의 입력값을 기준으로 검사한다.
- input.trim() === ""인지 확인하여, 공백임을 먼저 [ERROR] 처리한다.
- Number(input)를 사용해 입력값을 숫자로 변환한다.
- isNaN(number)를 사용해 숫자가 아닌 값을 확인한다.
- number < 1을 사용해 0 또는 음수를 확인한다.
- !Number.isInteger(number)를 사용해 소수를 확인한다.
- 위 조건 중 하나라도 만족하면 [ERROR]를 호출한다.
